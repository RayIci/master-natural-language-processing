\section{Levels of Linguistic Analysis}
\label{sec:linguistic-analysis}
\slidesrc{Terminology introduction: 23--33}

The course organises NLP problems following a standard linguistic analysis approach.
This short section introduces the three levels of that analysis, explains them with an
analogy from programming, and uses them as a map of the whole course.

This section covers:
\begin{enumerate}[nosep]
  \item the three levels: syntax, semantics, pragmatics (Section~\ref{sec:three-levels});
  \item the analogy with programming languages (Section~\ref{sec:programming-analogy});
  \item the map of the course topics, level by level (Section~\ref{sec:course-map}).
\end{enumerate}
